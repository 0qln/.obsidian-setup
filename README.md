# .obsidian Setup

Setup scripts for *.obsidian Repositories


## Usage

**Prerequisits**: Python installed.

1. Clone any *.obsidian repositories you want to use. (e.g. [appearance](https://github.com/0qln/appearance.obsidian), [keys](https://github.com/0qln/keys.obsidian))

2. Clone the repository under your Vault/.obsidian/ folder, so it looks like this:

```
MyValut/
├─ .obsidian/
│  ├─ .obsidian-setup/
│  ├─ *.obsidian/
│  ├─ ...
```

3. Execute the setup script: 
```
$ py setup.py
```
